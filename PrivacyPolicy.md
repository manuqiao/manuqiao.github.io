## 1. How We Collect Your Personal Information

To provide you with better services, we collect the following types of personal information:

### 1.1 Information You Provide

**（1）Registration and Login Information**
- **Email Address**: Used for account registration, login verification, and password recovery
- **Password**: Stored after encryption for account security verification

**（2）User-Created Content**
- **Question Bank Information**: Question bank name, description, creation time, etc.
- **Question Content**: Question stems, options, answers, etc.
- **Uploaded Images**: Photos used for OCR recognition to create question banks (images are sent to third-party OCR services after Base64 encoding, and original images are not permanently stored after recognition is complete)

### 1.2 Information We Automatically Collect

**（1）Answer Records**
- Answer time for each question, selected options, whether correct, etc.
- Used to provide features such as resume-from-break and wrong question statistics

**（2）Usage Statistics**
- Practice mode selection (sequential/random/exam)
- Practice duration, number of answers, accuracy rate, and other learning data
- Stored on local devices and cloud database to display learning statistics and progress

**（3）Device Information**
- Device model, operating system version
- App version number
- Network type (Wi-Fi/Mobile data)
- Used for device compatibility, troubleshooting, and service improvement

**（4）Log Information**
- App crash logs, error logs
- API request logs (excluding sensitive information such as passwords)
- Used for troubleshooting and performance optimization

### 1.3 Information Collected by Third-Party Services

To provide complete services, we use the following third-party services, which may collect some of your information:

| Third-Party Service | Purpose | Collected Information | Privacy Policy |
|---------------------|---------|------------------------|----------------|
| **Supabase** | Cloud database, user authentication, cloud storage | Email, user ID, answer records, question bank data | [Supabase Privacy Policy](https://supabase.com/privacy) |
| **SiliconFlow AI** | OCR image recognition, AI question analysis | Uploaded images (Base64), question content | [SiliconFlow Privacy Policy](https://siliconflow.cn/privacy) |
| **Google Play** | App payments, subscription management | Purchase records, payment information, subscription status | [Google Privacy Policy](https://policies.google.com/privacy) |

**Important Notes**:
- We do not directly obtain your payment password, bank card number, or other sensitive payment information; these are processed by the payment platform.
- Uploaded images are only used for OCR recognition, and original images are not permanently stored after recognition is complete.
- The data processing practices of third-party services are governed by their respective privacy policies. Please read them carefully.

### 1.4 Permission Application Description

To implement specific features, we need to apply for the following device permissions:

| Permission | Purpose | Required |
|------------|---------|----------|
| **Network Access Permission** (INTERNET) | Cloud data synchronization, question bank loading, AI service invocation | Yes (Core Function) |
| **Network State Permission** (ACCESS_NETWORK_STATE) | Detect network connection status, optimize data loading strategy | Yes (Core Function) |
| **Camera Permission** (CAMERA) | Take photos to create question banks | No (Optional Function) |
| **Storage/Album Permission** (READ_MEDIA_IMAGES) | Select images from album to create question banks | No (Optional Function) |

**Description**:
- If you refuse to grant camera or album permissions, it does not affect the use of other functions, but you will not be able to use the photo-taking feature to create question banks.
- You can modify these permissions at any time in your device's app management.

## 4. How We Protect Your Personal Information

### 4.1 Security Measures

We attach great importance to information security and have taken technical and management measures in line with industry standards to protect your personal information:

**（1）Data Transmission Security**
- All network communications use **HTTPS/TLS encryption protocol** to prevent data from being stolen or tampered with during transmission
- Plaintext HTTP transmission is disabled

**（2）Data Storage Security**
- Passwords are stored after **one-way encrypted hashing**, and we cannot obtain your plaintext password
- Cloud database uses **Row-Level Security (RLS)** to ensure users can only access their own data
- Data is stored with secure cloud service providers (Supabase), and data centers comply with international security standards

**（3）Access Control**
- Only authorized personnel can access user data, and access requires identity verification and permission approval
- We provide data security training to employees and have them sign confidentiality agreements

**（4）Security Audits**
- Regular security assessments and vulnerability scans
- Monitoring abnormal access and data breach risks

### 4.2 Security Incident Handling

Although we have taken the above measures, due to technical limitations and the complexity of the Internet, we cannot guarantee absolute information security. If a personal information security incident occurs, we will, as required by laws and regulations:
- Notify you in a timely manner: basic information about the incident, possible impacts, measures we have taken or will take, suggestions for you to independently prevent and reduce risks, etc.;
- At the same time, we will report the handling of the personal information security incident to regulatory authorities as required.

### 4.3 Information Retention Period

**We only retain your personal information for the period necessary to provide services**, unless laws and regulations require or you consent to a longer retention period.

- **Account Information**: Deleted or anonymized after you cancel your account
- **Answer Records**: Deleted after you cancel your account
- **Question Bank Data**: If you created a question bank that was also added by other users, the question bank data will be retained but disassociated from your account after account cancellation; if only you used it, it will be deleted
- **Log Information**: Generally retained for 6-12 months for troubleshooting and security audits
